# 引脚与接线

以下引脚根据综合工程源码整理。接线前应同时核对开发板和电机驱动板原理图，并确保所有模块共地。

| 功能 | STM32 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| 数码管段选 | PA0 至 PA7 | 输出 | 显示模式编号 1、2、3 |
| 红外遥控接收 | PA8 | 输入 | 下降沿外部中断 EXTI8 |
| 串口发送 | PA9 | 输出 | USART1 TX，9600 8N1 |
| 串口接收 | PA10 | 输入 | USART1 RX，9600 8N1 |
| 左侧避障传感器 | PA11 | 输入 | 上拉输入，低电平表示检测到信号 |
| 右侧避障传感器 | PA12 | 输入 | 上拉输入，低电平表示检测到信号 |
| 模式切换按键 | PA15 | 输入 | 上拉输入，按下为低电平 |
| 电机 PWM 1 | PB6 | 输出 | TIM4 CH1 |
| 电机 PWM 2 | PB7 | 输出 | TIM4 CH2 |
| 电机 PWM 3 | PB8 | 输出 | TIM4 CH3 |
| 电机 PWM 4 | PB9 | 输出 | TIM4 CH4 |
| 右侧循迹传感器 | PB12 | 输入 | 上拉输入 |
| 左侧循迹传感器 | PB13 | 输入 | 上拉输入 |

## 电源注意事项

- STM32、传感器和电机驱动模块必须共地。
- 电机电源应按电机和驱动模块额定电压供电，不要直接由 STM32 的 3.3 V 引脚驱动电机。
- 确认传感器输出电压与 STM32 GPIO 电平兼容。
- 首次测试时架空车轮，分别验证电机方向和传感器逻辑，再让小车落地运行。
